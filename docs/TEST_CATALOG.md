## Integration gate

1. Order placement contract is complete: documented request schema, vendor order id in the response, sync/async behaviour stated, and the address schema maps to our shipping fields. (ORD-01, ORD-02, ORD-04, ORD-05)
2. Orders are idempotent: our reference is accepted, a duplicate never creates a second order, and a timed-out order can be looked up by our reference. (IDM-01, IDM-02, IDM-03)
3. Order status is complete and mappable: enumerated statuses, every one maps to our six delivery statuses, an order-details lookup exists, and updates arrive by webhook or polling. (STS-01, STS-02, STS-03; any of WHK-01, POL-01; valid status map)
4. Shipment tracking (carrier plus tracking number or URL) is returned via API after dispatch. (TRK-01)
5. Serviceability of the regions/pincodes we need is confirmed, with documented behaviour for non-serviceable addresses. (ORD-14)
6. A returns, replacement or refund path exists for damaged, wrong or undelivered items. (RTN-03)
7. A reconciliation source of truth exists that carries our reference per line. (REC-01, REC-02)
8. Catalogue identifiers are stable and accepted unchanged by Place Order. (CAT-03)
9. Transport and authentication are secure and documented. (SEC-01, AUTH-01)
